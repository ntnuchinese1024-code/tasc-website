# 台灣性諮商學會 官方網站

TASC（Taiwan Association of Sexuality Counseling）官網原始碼與內容。取代原本即將到期的 Weebly 網站（`tasctaiwan.weebly.com`）。

## 這是什麼、為什麼長這樣

這個網站刻意選擇「純靜態網站＋Git 版本紀錄」的做法，而不是 Wix / Weebly / Squarespace 這類拖拉式平台，原因跟這次要重做網站的起因一樣：**平台到期或政策改變時，內容要能完整帶著走，不被鎖住。**

實際上這代表：
- 網站的每一個字、每一張圖，都是這個資料夾裡看得到、找得到的檔案（主要是 `src/content/` 底下的 Markdown），不是存在某個平台後台資料庫裡。
- 打包後（`npm run build`）產生的 `dist/` 資料夾，是純 HTML／CSS／JS，丟到**任何**網頁空間都能開——學會自己的主機、GitHub Pages、Netlify、Vercel，全部都行，沒有綁定。
- 修改紀錄用 Git 保存，未來不管換哪一任理事長、幹部或工作人員負責網站，都能看到「誰在什麼時候改了什麼」，不會因為換人交接就失去脈絡。

## 專案結構

```
tasc-website/
├── src/
│   ├── content/        ← 網站文字內容（Markdown），未來主要編輯的地方
│   └── pages/           ← 網站頁面架構（.astro 檔）
├── public/               ← 圖片、下載檔案等靜態資源
├── archive/
│   └── weebly-content/  ← 從舊 Weebly 網站搬過來的原始內容備份，供比對、遷移用
└── docs/
    └── 維護手冊.md        ← 給非工程背景的接手者看的操作說明
```

## 開發／預覽

```bash
npm install
npm run dev
```

在瀏覽器打開 `http://localhost:4321` 即可即時預覽（改檔案會自動刷新）。

## 發布上線

```bash
npm run build
```

會在 `dist/` 產生完整靜態網站，把整個 `dist/` 資料夾內容上傳到任何網頁空間即可。詳細部署方式見 `docs/維護手冊.md`。

## 內容遷移狀態

`archive/weebly-content/` 已完整保存原站七大主選單、20+ 子頁面的文字內容（2026-08-15 抓取）。部分頁面（如「歷年年會報導」「歷年講座」「歷年課程報導」）內容篇幅極大（十年份的活動報導），先以摘要＋清單方式存檔，並標註「如需展開全文請告知」。

正式內容遷移到新版網站架構前，建議先跟理監事會確認：
1. 舊站哪些內容要保留、哪些可以精簡（例如十年份的活動報導是否全部原文放上新站，或做成「精選回顧」）。
2. 「組織架構」「理監事會」兩頁原本是圖片（非文字），需要重新製作或提供最新資料。
3. 「性諮商師合格名單」等會不定期更動的名單，目前資料是 2024/09 版本，需要確認是否有更新。
