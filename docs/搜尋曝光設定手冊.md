# 讓 Google 與 AI 找得到學會網站

給沛辰與未來秘書處的操作手冊。**照順序做**，前面幾步的效果遠大於後面。

---

## 先理解：為什麼舊站找得到、新站找不到

這不是新站做壞了，是三件事疊在一起：

1. **新網域沒有歷史**。`tasctaiwan.tw` 是 2026-08-21 才啟用的，Google 對它一無所知。舊的 `tasctaiwan.weebly.com` 累積了好幾年，排名是那幾年攢下來的。
2. **舊站還活著**（我查過，現在仍回 HTTP 200）。兩個網站有幾乎一樣的內容，Google 會繼續把流量給它認識的那個，新站反而被當成抄襲的分身。
3. **新站到今天為止都在擋搜尋引擎**。上線前 `robots.txt` 是 `Disallow: /`，等於明確告訴 Google 不要收錄。這一項已經解除了。

**所以最有效的一步不是「優化新站」，是「把舊站的權重交棒給新站」。** 第一步就是做這件事。

---

## 第一步：處理舊的 Weebly 站（影響最大）

只要舊站還在，新站就一直在跟它競爭同一批關鍵字，而且會輸——因為 Google 認識它比較久。

**最好的做法是「301 轉址」**：告訴 Google「這個網址永久搬到新家了」，它會把累積的排名逐步移轉過去。這比直接關掉好很多，關掉只是讓排名消失，沒有人繼承。

Weebly 後台的操作位置依方案而異，找這幾個地方：

- **Settings → SEO → 301 Redirects**
- 或 **Settings → General → Site Redirect**

把整站轉向 `https://tasctaiwan.tw`。如果 Weebly 的方案不支援 301：

- **退而求其次**：把舊站首頁改成一句「本會網站已搬遷至 https://tasctaiwan.tw」加一個連結，其餘頁面全部刪除或隱藏。效果比 301 差，但比放著不管好得多。
- **最下策**：直接關站。排名會歸零，但至少不再跟新站打架。

> **千萬不要把舊站原封不動放著。** 那是目前最傷的狀態。

舊站如果有對外公告過的網址（FB 貼文、名片、合作單位的連結），也一併請對方改成新網址——那些連結是排名的重要來源。

---

## 第二步：Google Search Console（必做）

這是你跟 Google 溝通的唯一正式管道，也是唯一能看到「Google 到底怎麼看你的網站」的地方。

### 2-1 加入網站

1. 開 <https://search.google.com/search-console>，用學會的 `tasc.tw@gmail.com` 登入
2. 左上角 **新增資源** → 選 **網域**（不是「網址前置字元」）→ 填 `tasctaiwan.tw`
3. 它會給你一筆 **TXT 記錄**，長得像 `google-site-verification=xxxxx`
4. 到 **Cloudflare → tasctaiwan.tw → DNS → Records → Add record**：
   - Type：`TXT`
   - Name：`@`
   - Content：貼上 Google 給的那整串
5. 回 Search Console 按 **驗證**。通常幾分鐘內通過

> 選「網域」而不是「網址前置字元」，一次就涵蓋 `tasctaiwan.tw`、`www.` 與 http/https 所有版本，不用加四次。

### 2-2 提交 sitemap

sitemap 是一份「這個網站有哪些頁」的清單，我已經幫你做好了，共 **71 頁**，網址是：

```
https://tasctaiwan.tw/sitemap-index.xml
```

Search Console → 左邊 **Sitemap** → 貼上 `sitemap-index.xml` → **提交**。

狀態變成「成功」就對了。Google 通常幾天內開始逐頁收錄。

### 2-3 請 Google 優先看首頁

Search Console 最上方的搜尋框貼上 `https://tasctaiwan.tw/`，按 Enter，然後按 **要求建立索引**。

這等於插隊。**一天只能用幾次**，留給最重要的頁面：首頁、關於我們、性諮商師名單、最新消息。

### 2-4 兩週後回來看

- **索引 → 網頁**：看有多少頁被收錄了。目標是接近 71
- **成效**：看實際有多少人從搜尋點進來、用什麼關鍵字找到你

沒被收錄的頁面，那裡會寫原因。看不懂就把畫面截圖問我。

## 第三步：開放 AI 爬蟲（你要的那項，目前還沒生效）

我剛才檢查過，`robots.txt` 裡這些仍然是**禁止**狀態：

```
GPTBot、ClaudeBot、Google-Extended、CCBot、Bytespider、
Amazonbot、Applebot-Extended、meta-externalagent
```

這是 Cloudflare 自動注入的（不是我們寫的），要在它的後台關掉：

**Cloudflare → 選 `tasctaiwan.tw` → 左邊選單找 AI Crawl Control**（也可能叫 **Bots → AI Scrapers and Crawlers**）

把 **managed robots.txt** 或 **Block AI bots** 之類的開關**關閉**。同一區如果還有「主動封鎖 AI 爬蟲」的選項，也一起關掉——那個是真的擋連線，不只是 robots.txt 的君子協定。

改完用這行確認：

```bash
curl -s https://tasctaiwan.tw/robots.txt
```

**看到的內容應該只剩兩行**：

```
User-agent: *
Allow: /
```

還看得到一堆 `Disallow` 就是沒關成功。

> 提醒：`Google-Extended` 只影響 AI 訓練，**不影響一般 Google 搜尋排名**。所以這一步是為了讓 ChatGPT、Claude 這類工具在回答問題時能引用學會的內容，跟第二步的目標不一樣，兩件事都要做。

---

## 第四步：建立外部連結（長期最有效，也最花時間）

Google 判斷一個網站重不重要，最主要的依據是「有多少其他網站連向它」。新網域最缺的就是這個。

按投入報酬排序：

1. **學會的 Facebook 粉專**：簡介欄的網址改成 `https://tasctaiwan.tw`，並發一篇貼文公告搬家
2. **理監事、講師的個人網站或機構頁**：請他們在介紹自己時附上學會網址
3. **合作單位**：學校諮商中心、心理師公會、相關學會的「相關連結」頁面
4. **課程報名頁**：如果還在別的平台辦活動，主辦單位欄位填學會網址
5. **學術場合**：研討會論文、講座簡報的最後一頁放上網址

> 不要買連結、不要參加「交換連結」的網站。Google 抓得到，會反過來扣分。

---

## 第五步：內容本身（持續做）

新網站已經有的（我做好了，不用你動手）：

- 每頁的 canonical、`<title>`、description
- sitemap（71 頁）
- Open Graph 標籤（分享到 FB、LINE 會有預覽卡片）
- Organization 結構化資料（讓 Google 知道這個網站代表哪個組織）

**你能持續做、而且最有效的一件事：課程報導。**

每一篇報導都是一個新的頁面、一組新的關鍵字。「性諮商 課程」「性諮商師 培訓」這種詞很難跟大機構搶，但「月經平權 講座 心得」「偷拍行為人 諮商」這種具體的題目，學會的報導很可能是全台灣寫得最深入的——那才是你的優勢。

寫報導的時候：

- **標題寫具體的主題**，不要寫「2026 秋季課程報導」這種看不出內容的
- **前兩句話就講清楚這篇在講什麼**，那通常會變成搜尋結果的摘要
- **提到講師姓名與專業領域**，有人搜尋講師名字時就找得到學會

---

## 第六步：確認搬家順利（一個月後）

Google 搜尋這一行：

```
site:tasctaiwan.tw
```

會列出所有被收錄的頁面。數字接近 71 就代表收錄完成。

再搜尋 `台灣性諮商學會`，看：

- **新站有沒有出現、排第幾**
- **舊的 weebly 站還在不在**（第一步做對的話，會逐漸消失）

三個月內新站應該要接手舊站原本的位置。沒有的話，帶著 Search Console 的畫面來找我看。

---

## 時間感

| 項目 | 多久看得到效果 |
|---|---|
| Search Console 驗證與提交 sitemap | 當天 |
| 首頁被收錄 | 幾天到兩週 |
| 全站 71 頁收錄完 | 二到四週 |
| 搜尋學會名稱能排到前面 | 一到三個月 |
| 舊站的排名轉移過來 | 三到六個月 |

**不要因為第一週沒動靜就慌。** 唯一真的會拖慢一切的，是舊 Weebly 站繼續放著不處理。

---

## 一句話總結

如果只做一件事，就做**第一步**（把舊站 301 轉到新站）。
如果做兩件，加上**第二步**（Search Console 驗證＋提交 sitemap）。
其餘都是加分題。
